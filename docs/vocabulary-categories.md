# معیار دسته‌بندی واژه‌ها

`data/categories.json` مرجع واحد نام، ترتیب، برچسب فارسی، آیکن، رنگ و نوع دسته‌هاست. `tools/rebuild.js` همین فایل را به `window.VOCAB_CATS` داخل HTML نهایی تبدیل می‌کند و `tools/validate.js` نیز فهرست مجاز `cat` را از همان‌جا می‌خواند.

## قاعدهٔ تخصیص

هر مدخل فعلاً یک `cat` دارد. برای اینکه این محدودیت به نتیجه‌ای قابل پیش‌بینی برسد، اولویت به این ترتیب است:

1. اگر واژه به‌روشنی به یک موضوع تعلق دارد، دقیق‌ترین دستهٔ موضوعی انتخاب می‌شود؛ برای نمونه `passport → travel`، `piano → music` و `diabetes → health`.
2. اگر موضوع مشخصی ندارد، نقش دستوریِ معنای ثبت‌شده انتخاب می‌شود: `noun`، `verb`، `adj` یا `adv`.
3. ترکیب‌ها، افعال عبارتی و اصطلاح‌های چندکلمه‌ایِ بدون موضوع روشن در `phrase` قرار می‌گیرند.
4. `general` برای واژه‌های دستوری‌ای است که چهار نقش بالا پوشششان نمی‌دهد (مانند حرف تعریف، حرف اضافه و ضمیر)، و نیز fallback واژهٔ شخصی یا مدخل واقعاً نامشخص؛ نباید جایگزین بررسی شود.

در واژه‌های چندمعنا، معنی فارسی و جملهٔ نمونهٔ همان رکورد تعیین‌کننده‌اند. صرفاً پسوندی مانند `-ly` یا اولین معنای فرهنگ لغت برای تغییر دسته کافی نیست.

## دامنهٔ موضوع‌ها

- `food`: خوراک، نوشیدنی، مواد اولیه و آشپزی
- `travel`: سفر، گردشگری، فرودگاه و هتل به‌عنوان خدمت سفر
- `car`: خودرو، حمل‌ونقل، راه و رانندگی
- `house`: خانه، اتاق‌ها، وسایل خانه و اقامت
- `place`: مکان‌ها، بناها و عوارض شهری
- `nature`: طبیعت، گیاهان، محیط‌زیست و جغرافیای طبیعی
- `weather`: وضعیت و پدیده‌های آب‌وهوایی
- `animal`: جانوران و واژگان مستقیم مربوط به آن‌ها
- `body`: اعضای بدن، ظاهر، آرایش و حرکات بدن
- `health`: بیماری، درمان، پزشکی و تندرستی
- `clothes`: پوشاک، کفش، زیورآلات و اکسسوری
- `feeling`: احساس، خلق‌وخو و حالت روانی
- `people`: افراد، خانواده، رابطه و ویژگی‌های شخصیتی
- `work`: شغل، محیط کار و کسب‌وکار
- `money`: پول، بانک، قیمت، خرید و فروش
- `school`: آموزش، درس، پژوهش و دانش
- `talk`: گفت‌وگو، زبان و ارتباط
- `tech`: رایانه، اینترنت، نرم‌افزار و ابزار دیجیتال
- `movie`: فیلم، تلویزیون و نمایش
- `music`: موسیقی، اجرا و سازها
- `sport`: ورزش، مسابقه و تناسب اندام
- `crime`: قانون، جرم، پلیس و دادگاه
- `time`: زمان، تاریخ، دوره و بسامد زمانی

وقتی دو موضوع ممکن‌اند، موضوعی انتخاب می‌شود که معنی و مثال را مستقیم‌تر توضیح می‌دهد؛ مثلاً `flight attendant` در `travel` می‌ماند، نه `work`.

## روند تغییر امن

تغییر دسته‌ها فقط با patch مبتنی بر `i` انجام می‌شود. `i`، `en` و `VOCAB_ORDER` نباید جابه‌جا شوند، چون پیشرفت کاربر به آن‌ها وابسته است.

```bash
node tools/apply.js --dry
node tools/apply.js
node tools/validate.js
node tools/repack.js --dry
node tools/repack.js
node tools/rebuild.js --dry
node tools/rebuild.js
node tools/audit-categories.js
```

کلیدهای دسته عمداً ثابت نگه داشته شده‌اند تا `vocab_catover`، backupها و topicهای بخش Listening معتبر بمانند. override صریح کاربر همچنان بر دستهٔ پایه اولویت دارد.
