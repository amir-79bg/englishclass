# Claude repository entrypoint

Before changing this repository, read and follow these files in order:

1. `AGENTS.md`
2. `docs/EXECUTION_PLAN.md`

The files under `.claude/agents/` were created for the legacy HTML/content workflow. Do not use them to define the Laravel/Android architecture unless the execution plan explicitly says to do so.

Every implementation must use a task ID and update the canonical execution plan with verified status in the same change.
